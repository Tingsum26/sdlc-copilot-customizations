# SDLC Prompt Files

These are copyable **entry prompts** for VS Code GitHub Copilot. The SDLC
Workbench installs the catalog into its managed prompt location and activates
`chat.promptFilesLocations`; without the workbench, copy the needed files into
the Journey repository's `.github/prompts/` folder. Choose the named Agent
before running the prompt when VS Code does not select its `agent` frontmatter
automatically.

Prompt files collect only the current task parameters. Agent profiles, Skills,
Instructions, policies and deterministic scripts remain authoritative for
permissions, Context Receipts, validation, publication and stage gates.

Never paste credentials, customer data, source code from an unapproved
repository, or hidden internal URLs into a prompt. Provide links/IDs and let
the local Agent read only the authorised workspace and local MCP sources.

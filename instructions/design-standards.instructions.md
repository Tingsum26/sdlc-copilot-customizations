# Design Standards

- Follow the solution-design template; every design carries a compatibility section.
- Significant decisions become ADRs with alternatives and consequences.
- Diagrams use Mermaid; the design artifact is versioned and human-reviewed.

## Artifact quality bar

A design is reviewable only when it states scope/non-scope, assumptions,
alternatives, sequence/data/error flows, API compatibility, security/privacy,
observability, migration/rollback, flag and native release strategy, test
strategy, manual E2E gaps, and decision owners. Mermaid diagrams need a legend
and must match the prose.

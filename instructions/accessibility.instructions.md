# Accessibility

- Baseline WCAG 2.2 AA; VoiceOver/TalkBack and keyboard verified.
- Findings carry severity and violated guideline; BLOCKER keeps the merge gate red.
- Automation findings never replace human sign-off.

## Review checklist

Check semantics/names, keyboard and switch access, focus on route/modal/error
changes, contrast/non-color cues, zoom and text scaling, reduced motion,
dynamic content announcements, localization, form errors, touch target size,
and screen-reader order. Separate static evidence from manual
VoiceOver/TalkBack/NVDA results. A BLOCKER includes criterion, location,
affected user group, reproduction, and remediation.
